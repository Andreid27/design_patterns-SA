# Design Patterns & Book Store Project

This repository contains a full-stack application demonstrating various design patterns, featuring a Spring Boot backend and a Flutter mobile application.

## Project Structure

- **`backend/`**: A Spring Boot application implementing behaviorial, creational, and structural design patterns.
- **`mobile/`**: A "Book Store" Flutter application with role-based features (Admin/Buyer).

## Getting Started

### Backend

Navigate to the `backend` directory and run the Spring Boot application.
_(Refer to internal backend documentation for specific setup)_

### Mobile App

Navigate to the `mobile` directory for the Flutter app.

```bash
cd mobile
flutter pub get
flutter run
```

## Features

- **Book Management**: Admin interface for managing book inventory.
- **E-Commerce**: Buyer interface for browsing and purchasing books.
- **Authentication**: Secure login using Keycloak.
